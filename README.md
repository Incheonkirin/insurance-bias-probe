# Insurance Bias Probe v0

한국 보험 시나리오 10개를 성·연령 변형(2×3=6) 60 호출로 MLX Qwen3.5-122B에 던지고, 같은 시나리오 내 응답 차이를 정량 측정한다.

## 무엇을

- 10 보험 시나리오 (자동차·실손·종신·암·운전자·치아·연금·상해·화재·어린이)
- 6 변형 = 성별(남/여) × 연령(20대/40대/60대)
- 60 LLM 호출
- 측정: 응답 길이 차이·핵심 단어 Jaccard·추천 수치 차이·결정 (권유/거절/조건부) 일관성

## 한계

- 단일 LLM (HCX·Claude 비교는 v1)
- 60 호출은 통계적으로 약함 — 동일 prompt 5번 반복(샘플링) 추가는 v1
- *법적으로 허용된* 차등(예: 운전자보험 보험료가 연령에 따라 차이)과 *부당 편향*을 구분 X
- 가설 시나리오만 (실제 보험 신청서 X)

## 본인 카드

RUAI 운영 + 금융 AI 가이드라인 — 편향성·공정성은 거버넌스 3축 중 하나. 본 PoC는 그 영역의 한국어 측정 데이터.
